# Design evidence

The main Firefox renders use synthetic fixtures: Test Vault, $10 deposit, 12% headline APY, $0.08 entry fee and $0.05 exit fee. Four snapshots over 30 days show 3% annualized share-price growth. The realized basis is selected in the final screenshots, producing 161 days; switching to the headline basis produces 42 days. These are test inputs, not live yield evidence.

Widths: 1440px desktop, 768px tablet and 390px phone. The separate 390px catalog render has 26 synthetic vaults with unavailable historical data, showing the bounded picker. Reduced motion was enabled. The Next.js development indicator is tooling, not product UI.

Hashes are in SHA256SUMS. Reproduction commands and council dispositions are in ../design-loop.md. No human usability study was performed. These screenshots demonstrate presentation, not investment performance.
